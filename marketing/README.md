# Маркетинговые материалы SeasonScout

Здесь лежат готовые материалы для продвижения сайта. Тексты для публикаций написаны на английском, потому что аудитория сайта — США и Великобритания.

| Файл | Что внутри |
|---|---|
| [`social-calendar.md`](social-calendar.md) | Календарь публикаций на 12 месяцев: какие страницы продвигать и когда |
| [`press-pitches.md`](press-pitches.md) | Идеи историй на данных для журналистов и шаблон письма |
| [`outreach.md`](outreach.md) | Шаблоны писем для блогеров (виджет), гостевых постов, экспертных платформ и туристических офисов, а также правила для Reddit и Quora |
| `pins/` | Пины для Pinterest: по 3 дизайна на каждую страну или регион. Создаются командой `npm run build && npm run pins` и в git не хранятся |

Pinterest показывает пины за 2–3 месяца до сезона. Поэтому публикуйте пин «Best time to visit Japan» с цветением сакуры уже в январе, а «Where to go for Christmas» — в сентябре или октябре.

# SeasonScout — куда поехать в любой месяц

Англоязычный сайт для зарубежной аудитории: 38 популярных направлений с оценкой погоды по каждому месяцу, климатическими графиками, бюджетом на день и партнёрскими ссылками Travelpayouts.

Сайт статический (Astro): **514 страниц**, база данных и сервер не нужны. Размещается бесплатно на Cloudflare Pages.

## Какие страницы есть

| Страница | Пример | Зачем нужна |
|---|---|---|
| Главная | `/` | Выбор месяца, топ направлений текущего месяца |
| Куда поехать в месяце (12 шт.) | `/where-to-go-in-october/` | Под запросы «where to go in October». Фильтры по региону, температуре и бюджету |
| Направление (38 шт.) | `/destinations/lisbon/` | Под запросы «best time to visit Lisbon». Графики, таблица, бюджет, бронирование |
| Город + месяц (456 шт.) | `/destinations/lisbon/october/` | Под запросы «Lisbon in October weather». Основной источник поискового трафика |
| Календарь | `/calendar/` | Тепловая карта: все города × 12 месяцев |
| Методология, раскрытие партнёрских ссылок, приватность, авторы фото | `/about/` и др. | Доверие пользователей и требования партнёрских программ |

## Как добавить партнёрские ссылки (главное для заработка)

Все ссылки хранятся в одном файле: **`src/data/affiliates.json`**.

```json
"flights": { "label": "Flights", "brand": "Aviasales", "cta": "Find cheap flights", "url": "" }
```

1. В кабинете Travelpayouts подключитесь к программам: авиабилеты, отели, экскурсии, страховка, eSIM.
2. Для каждой программы создайте ссылку в генераторе ссылок.
3. Вставьте ссылку в поле `url` нужного блока. Кнопка появится на всех страницах сразу. Пока `url` пустой, кнопка скрыта.
4. Уже подключён **GetTransfer** (трансферы).

Отдельную ссылку для конкретного города, например поиск отелей в Бангкоке, можно задать в `overrides`:

```json
"overrides": {
  "bangkok": { "hotels": "https://...ваша ссылка на отели Бангкока..." }
}
```

Все партнёрские ссылки автоматически получают `rel="sponsored nofollow"` (так требует Google) и открываются в новой вкладке.

## Как опубликовать на Cloudflare Pages (бесплатно)

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com). Карта не нужна.
2. **Workers & Pages → Create → Pages → Connect to Git** → выберите репозиторий `newlife`.
3. Настройки сборки:
   - Production branch: ветка с сайтом (`main` после слияния или текущая ветка);
   - Framework preset: **Astro**;
   - Build command: `npm run build`;
   - Build output directory: `dist`.
4. **Save and Deploy**. Через пару минут сайт откроется по адресу `https://<имя-проекта>.pages.dev`.
5. Если имя проекта не `seasonscout` или подключён свой домен, поменяйте `url` в **`src/config.ts`**. От него зависят sitemap и канонические ссылки.

Дальше каждый push в эту ветку будет публиковать сайт автоматически.

После публикации добавьте сайт в [Google Search Console](https://search.google.com/search-console) и [Bing Webmaster Tools](https://www.bing.com/webmasters) и отправьте карту сайта `https://ваш-домен/sitemap-index.xml`.

## Откуда данные

- **Климат** (`src/data/climate.json`): нормы национальных метеослужб, обычно за 1991–2020 годы, из таблиц «Climate data» в Википедии. Если в таблице нет осадков, они берутся из NASA POWER. Обновить данные: `npm run climate`.
- **Фото** (`src/assets/destinations/`, авторы в `src/data/images.json`): Wikimedia Commons, только свободные лицензии (CC BY, CC BY-SA, CC0). Авторы указаны на страницах и на `/photo-credits/`. Обновить фото: `npm run images`.
- **Оценка погоды** (`src/lib/score.ts`): 55% температура и 45% осадки, с поправками на сезон дыма, ураганы и муссоны. Формула описана на странице `/about/`.
- **Тексты, бюджеты, события** (`src/data/destinations.json`): здесь же добавляются новые направления. После добавления запустите `npm run climate` и `npm run images`.

## Структура

```
src/
  config.ts              название и адрес сайта
  data/
    affiliates.json      ← партнёрские ссылки
    destinations.json    направления: тексты, бюджеты, события, поправки
    climate.json         климат (генерируется скриптом)
    images.json          авторы фото (генерируется скриптом)
  lib/                   оценка погоды, работа с данными, SEO
  components/            карточки, графики, фильтры, блок бронирования
  pages/                 страницы сайта
scripts/                 сбор климата и фото
```
